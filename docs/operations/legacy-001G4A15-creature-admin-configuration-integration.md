## Production blockers and next slice

**Local integration demonstrated; production installation remains NO-GO.** Remaining gates:

1. Existing runtime UI/DML still sends HP or assigns/deletes directly. Fixture translation/private guards provide no deployed containment. A real server-owned explicit patch/config contract and narrowly scoped raw protected-write authority design are required before production authoring; a late row trigger acquiring node locks is unsuitable.
2. Full save semantics for level/rarity/stats/aggression/boss fields and stale configuration need explicit mapping/expected-state handling. They are refused by this metadata-only translation rather than silently discarded. No rate control was added. PopulatePanel/loot editors and trusted external writers are not covered by this proof.
3. Retained deletion/history and NULL-node unassignment need an explicit disposition before broad support. The private guard keeps references intact; it does not authorize deleting history. Missing destination encounters and active-node creation remain conservative coverage limits.
4. Fresh installed DML/RLS/trigger/dependency/role parity and actual production caller isolation remain unverified. Source role checks are not proof of exclusive effective table authority. Full unique reward/holder, constraints, Arena/scheduler/maintenance and raw legacy writer composition remain separate gates. No G3D workaround or hosted route is proposed.
