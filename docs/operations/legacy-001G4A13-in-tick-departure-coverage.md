## Early coverage protocol

| Stage | Discovery / locks / action |
|---|---|
| Discover before gates | Origin encounter; moved proposal destinations; origin fighters/request actors and their parties; accepted and pending membership IDs/status/follow flags; member locations; authored creatures on touched nodes and current-generation projections attached there; all retained projection, fighter and active-party-group encounter references. |
| Node coverage | Sorted, deduplicated union of touched nodes, discovered member nodes and retained encounter/creature nodes. Acquire combat_enter_node advisory gates first, then global party-lifecycle. Recompute the entire coverage JSON; mismatch raises40001. No retry/spin inside the adapter. |
| Encounter coverage | Lock discovered existing encounter UUIDs in sorted order. Revalidate before dependent locks. A retained projection whose authored node disagrees with its encounter is refused, not relocated/healed. |
| Dependent coverage | Lock only discovered current-generation projection IDs, then discovered creature IDs, in sorted order. Revalidate again under these row locks. Do not call a helper that might acquire an undiscovered node before this check. Old-generation unrelated projection rows are not included merely because they share a creature ID. |
| Before source mutation | Source origin/node and proposed current-generation guards remain. For a not-yet-committed tick, fence only touched destination creature leases and settle eligible time using the unchanged G4A6 authority, inside the refusal rollback block. All node/encounter/dependent locks are already held. Never settle unrelated off-node members' creatures. |
| Full source commit / arrival | Invoke unchanged outer stance/inner commit chain. Existing node gates and existing encounter/creature locks are reentrant. New destination encounter/projection rows are created by the supported arrival under the held destination node gate, not by a fabricated precreation. They are new rows owned by this transaction, not a late wait on a previously undiscovered existing encounter. |
| Success / refusal / replay | Reconcile touched creatures only after committed. False result raises/catches private rollback sentinel, reverting attempted accounting and all movement; source bounded failure also rolls back partial effects/resources/requests. Existing successful tick replay calls source without repeating destination settlement. Source stance-before-inner-replay refusal remains as documented in G4A12. |

No unrelated off-node creature is mutated despite its party member node being covered. Inconsistent same-generation HP or authored-node/projection-node state refuses without repair.
