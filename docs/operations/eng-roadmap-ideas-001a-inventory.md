## Scope and evidence interpretation

Bounded documentation discovery: engine roadmap; project-state JSON/generated view/product_backlog; admin maintenance backlog; relevant design proposals and accepted progression/legacy C–F findings. No code TODO scan, hosted inspection or World-domain audit. Historical implementation plans, installation instructions and repeated limitations are grouped rather than counted once per report. Not an exhaustive index of every document sentence or authored gameplay rule. Documentation lacks a complete hosted product-idea export: Cloud roadmap_items and UI-only ideas are outside this local evidence boundary.

IDs ENG/ADM are preserved. INV-Axx are **proposed report-local IDs**, not approved canonical IDs. IMPLEMENTED means the cited source says implemented/completed, often source-only; never implies installed/deployed/live-verified. IN PROGRESS includes live verification pending. IDEA maps roadmap planned/ready without inventing design approval. UNKNOWN preserves decision-needed or stale/conflicting evidence. NEEDS AUDIT means a documented open question needing focused evidence, not audit authorization. DEFERRED includes accepted unresolved findings; authoritative OPEN remains OPEN in the source-status column. Latest explicit owner closure supersedes historical open text, without closing its retained gaps.
